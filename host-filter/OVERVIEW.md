Adds a host dropdown to the top section of the left sidebar. The row shows which host the sidebar is showing; click it to pick one host, with its connection status shown as a colored dot, or "All hosts" to clear the filter. Cmd-click (Ctrl-click on Windows and Linux) adds or removes a host so several can be shown at once. Each online host also shows how many of its workspaces need you (needs input, attention or failed), the same rule as the dock badge, so you can tell which host the badge is about. It drives the same host filter as the sidebar's display menu.

The plugin SDK has no host filter API yet, so the plugin reaches into the desktop app's own sidebar state. It works on the desktop and web app only and may stop working after a Paseo update. On iOS and Android it adds nothing; the sidebar's display menu has the same host filter there.
