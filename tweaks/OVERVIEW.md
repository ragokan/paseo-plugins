Small changes to Paseo's app, mostly its sidebar: hiding the workspaces you pick, Idle and Waiting groups in the sidebar grouped by status, and how Idle and the hosts look.

Hides the sidebar's workspaces you pick, the groups like ragokan, coding or dev under its Workspaces heading (Paseo calls them projects), with their chats, pinned ones included, and their keyboard shortcuts. Open Hide Workspaces from Settings → Plugins. The page lists every workspace of every online host under Shown, one row per name, with the hosts that have it; the eye button on a row hides it. Hidden workspaces are listed under Hidden, where the other eye button shows them again. Hiding goes by name and is saved on every host the app reaches, so it applies in every app connected to them, the iOS and Android apps included, and a host that was offline or unreachable is named in an error to try again for. A name stays hidden while any host lists it. A workspace whose name starts with a digit, like a pull request's 7555-markdown-table, is always hidden, on every app and with nothing saved, and is listed under Hidden without a button.

Grouped by status, a workspace Paseo puts in Done waits in an Idle group, just above Done, for a day after it got there, then moves to Done on its own. Paseo puts a workspace in Done once none of its agents is working, waiting on you, failed or unread. Run Mark as done from the command palette, with the workspace open, to send it to Done before its day is up; it stays there until its status changes, and comes back to Idle if it ends up in Done again. That is saved on the workspace's host, so every app connected to it follows it, the iOS and Android apps included. Idle collapses on its own, and keyboard shortcuts skip it while it is collapsed.

A workspace in Done whose agent waits on a subagent sits in a Waiting group above Idle instead, with Working's icon. A subagent is an agent another agent started, or one that agent started in turn; it works in a workspace of its own, so Paseo puts its starter's workspace in Done while it still works. The workspace stays in Waiting while any of them is working, however long that takes, then moves on to Idle or Done. Subagents count on every host the app reaches, so one started on another machine keeps its starter waiting too. Mark as done does not apply in Waiting. For this, each host's copy of the plugin follows that host's agent list, background agents included; on a host with more than 200 active agents, only the first 200 count. Waiting collapses on its own too.

On the desktop and web apps, Idle's group icon is a minus in a circle, in the yellow of an amber label; on iOS and Android it keeps Done's check.

A host's name shows without the server icon in front of it, and a quarter fainter in its color, in the sidebar rows and wherever else Paseo shows a host's badge. A host set to show only its icon keeps it. In the sidebar rows the host comes first, before the folder, and the New workspace screen has the host picker before the project picker, and on the desktop and web apps shows the host's name without its status dot.

On the desktop and web apps, a label named Done is gray, like Paseo's Done group. Paseo's label colors have no gray, so the status-labels plugin gives Done indigo, which the iOS and Android apps show.

The plugin SDK has no API for any of this yet, so the plugin finds the app's own functions among the app's loaded code and wraps them: the sidebar layout, the sidebar rows' subtitle, the host badge and the New workspace form. Idle's icon, the status dot and the Done label are styles on the desktop and web apps' page. Any of it may stop working after a Paseo update. On iOS and Android it does the same, except those styles, but the page is not there, so hide workspaces from the desktop or web app.
