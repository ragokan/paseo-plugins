Keeps the sidebar's workspaces, the groups like ragokan, coding or dev under its Workspaces heading (Paseo calls them projects), in your order whichever hosts the sidebar shows. Open Organize Workspace Order from the top of the sidebar, or from Settings → Plugins. The page lists every workspace of every online host under Unordered, one row per name, with the hosts that have it; add the ones you want and arrange them with the arrows under Ordered. Only those are ordered: they lead the sidebar in that order, and the rest follow in Paseo's own order. With the host filter on, the ordered workspaces that host has keep their order.

The order goes by name, because Paseo's own saved order goes by a key that changes with the hosts shown: merge-projects keys a workspace on several hosts one way when all are shown and another way when one is, so Paseo's order does not carry over between them. Two workspaces with the same name are ordered together. Dragging an ordered workspace in the sidebar does not change the order; dragging the others still does. The order is saved in this app, like Paseo's own sidebar order, and an ordered workspace whose host is offline keeps its place.

The plugin SDK has no sidebar order API yet, so the plugin wraps the desktop app's own sidebar layout function. It works on the desktop and web app only and may stop working after a Paseo update. On iOS and Android it adds nothing.
