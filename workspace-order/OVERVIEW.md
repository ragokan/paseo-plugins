Keeps the sidebar's workspaces, the groups like ragokan, coding or dev under its Workspaces heading (Paseo calls them projects), in your order whichever hosts the sidebar shows, and hides the ones you pick. Open Organize Workspaces from the top of the sidebar, or from Settings → Plugins. The page lists every workspace of every online host under Unordered, one row per name, with the hosts that have it; add the ones you want and arrange them with the arrows under Ordered. Only those are ordered: they lead the sidebar in that order, and the rest follow in Paseo's own order. With the host filter on, the ordered workspaces that host has keep their order.

The order goes by name, because Paseo's own saved order goes by a key that changes with the hosts shown: merge-projects keys a workspace on several hosts one way when all are shown and another way when one is, so Paseo's order does not carry over between them. Two workspaces with the same name are ordered together. Dragging an ordered workspace in the sidebar does not change the order; dragging the others still does. The order is saved in this app, like Paseo's own sidebar order, and an ordered workspace whose host is offline keeps its place.

The eye button on a row hides that workspace from the sidebar, with its chats, pinned ones included, and its keyboard shortcuts; it also leaves the order. Hidden workspaces are listed under Hidden, where the other eye button shows them again. Hiding goes by name and is saved on every host the app reaches, so it applies in every app connected to them, the iOS and Android apps included, and a host that was offline or unreachable is named in an error to try again for. A name stays hidden while any host lists it. A workspace whose name starts with 0, like 0-scratch, is always hidden, on every app and with nothing saved, and is listed under Hidden without a button.

The plugin SDK has no sidebar API yet, so the plugin finds the app's own sidebar layout function among the app's loaded code and wraps it. It may stop working after a Paseo update. On iOS and Android it hides workspaces but does not order them, and the page is not there: those apps keep no storage for the order, so pick hidden workspaces from the desktop or web app.
