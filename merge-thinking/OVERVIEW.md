Folds the thinking rows around tool calls into the collapsed tool call group, so a turn that alternates thinking and commands shows one "Thought 4 times and ran 4 commands" row instead of a Thinking row before every command. Expand the group to read each thought in order between the commands. Thinking that ends a run of tool calls, such as the thought before the reply or the one being written, joins the group too, and the group shows its spinner while that thought streams. Two or more thoughts in a row with no tool call next to them, such as several Thinking rows before a reply, fold into one "Thought 4 times" row; a single thought on its own stays as it is.

The plugin SDK has no tool call grouping or label API yet, so the plugin wraps the desktop app's own grouping functions and its translation function. It works on the desktop and web app only, may stop working after a Paseo update, and on iOS and Android it changes nothing. It applies to the Summary tool call display; Detailed shows every row as before. The thought count is worded in English in every language. Thoughts inside a group start collapsed even when thinking is set to show expanded.
